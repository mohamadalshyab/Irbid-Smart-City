# 🚦 Irbid Smart City - AI Traffic Prediction Dashboard

## 📌 Overview
An end-to-end AI platform that predicts traffic congestion levels across the streets of Irbid city based on time and weather conditions. This project applies Smart City concepts to provide proactive traffic management solutions and data-driven urban planning.

## ✨ Key Features
* **Data-Driven Prediction:** Utilizes a `Random Forest` machine learning algorithm to analyze historical and simulated traffic patterns.
* **Live Interactive Map:** Geospatial representation of predictions using `Folium`, where city zones and streets are color-coded dynamically based on expected congestion.
* **Dynamic Dashboard:** A fully interactive, responsive, and user-friendly interface built with `Streamlit`.

## 🛠️ Tech Stack
* **Data Processing & Engineering:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn
* **Geospatial Visualization:** Folium, Streamlit-Folium
* **Deployment & Cloud:** Streamlit Community Cloud
